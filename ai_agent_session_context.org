** Key Technical Concepts

*** Semantic Equivalence
Commands like "control e that" map semantically to "(end-of-line)" regardless of exact syntax. The system learns these equivalences through usage patterns.

*** Background Learning
Agents continuously improve through Redis streams without blocking user interactions. Learning happens asynchronously and feeds back into future command processing.

*** State Diff Architecture
Instead of imperative commands, the system thinks in state transitions: "current state → desired state → minimal elisp diff to achieve transition"

*** Hybrid Coordination
MCP servers provide immediate structured responses while Redis enables deeper coordination, learning, and state persistence across sessions.
